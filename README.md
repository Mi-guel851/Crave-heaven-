# Crave Heaven
Responsive restaurant website built with React and Vite.

## Development
`npm install` then `npm run dev`.

## Production
`npm run build`; deploy the `dist` directory.

Includes category filtering, a local in-memory basket, reservation/event preview forms, and a newsletter confirmation. Menu items and prices are illustrative. Forms and ordering are frontend demonstrations, not connected to a backend or payment service. Replace sample menu data and connect business services before launch. Food imagery includes an AI-generated hero and externally hosted Unsplash photographs.
